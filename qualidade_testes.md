- Foi verificado a praticidade do projeto(DevCafé).

--> O objetivo do projeto é a criação e organização de uma rotina do seu dia a dia.

--> Os botões são responsivos e intuitivos. É fácil, rápido e simples criar uma nova tarefa, estabelecer uma data para a tarefa criada. Também é possível estabelecer o nível de prioridade para as tarefas. 
Interface com identidade própria: a proposta visual do DevCafé utiliza linguagem acolhedora, elementos decorativos e mensagens motivacionais.
Organização das funcionalidades: há separação entre visão geral, tarefas e anotações, o que facilita a navegação.
Gerenciamento de tarefas: o cadastro contempla nome, descrição, categoria, prazo, prioridade e status.
Acompanhamento de produtividade: os indicadores de tarefas pendentes, em andamento, concluídas e atrasadas ajudam o usuário a acompanhar suas atividades.
Funcionalidades complementares: calendário, modo escuro, busca, filtros e opções de backup tornam o projeto mais completo
