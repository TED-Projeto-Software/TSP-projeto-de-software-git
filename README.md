# DevCafé

Este repositório tem como objetivo registrar o desenvolvimento de um sistema voltado à organização de atividades acadêmicas e acompanhar o processo de trabalho da equipe utilizando conceitos do Team Software Process (TSP).

## Cenário

O projeto busca auxiliar estudantes na organização de suas atividades acadêmicas, permitindo visualizar tarefas, prioridades e andamento das atividades em um único sistema.

A proposta surgiu da necessidade de reunir, em um único ambiente, informações relacionadas às tarefas acadêmicas e facilitar o acompanhamento das atividades que ainda precisam ser realizadas e daquelas que já foram concluídas.

## Produto

Escolhemos o **Caminho B**, que consiste no desenvolvimento de um sistema ou site com lógica de funcionamento.

O projeto foi desenvolvido como um sistema web de pequeno porte, priorizando tanto o funcionamento do produto quanto a organização do processo de desenvolvimento da equipe.

Apesar de o produto ser simples, buscamos criar uma aplicação funcional e interativa que pudesse ser utilizada e apresentada de forma online.

## Funcionalidades

O sistema possui funcionalidades voltadas à organização das atividades acadêmicas, permitindo:

1. Cadastrar novas tarefas.
2. Visualizar as tarefas cadastradas.
3. Alterar o status das tarefas.
4. Organizar tarefas de acordo com prioridade ou situação.
5. Visualizar tarefas concluídas.
6. Acompanhar o progresso das atividades.
7. Utilizar calendário para organização das tarefas.
8. Criar anotações.
9. Pesquisar informações dentro do sistema.
10. Utilizar recursos de organização e acompanhamento das atividades.

## Organização do projeto

O acompanhamento das atividades do grupo foi realizado por meio do GitHub Projects.

O quadro Kanban foi dividido nas seguintes etapas:

- A fazer
- Fazendo
- Em revisão
- Feito

As tarefas foram distribuídas entre os integrantes e movimentadas no quadro de acordo com o andamento do trabalho.

Durante o desenvolvimento, algumas atividades foram concluídas de maneira diferente do planejamento inicial. Essas diferenças foram registradas para permitir a comparação entre o que foi planejado e o que realmente aconteceu durante o projeto.
